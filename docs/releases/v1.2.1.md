## LeanTerm 1.2.1

### Install

**Linux** (Debian 13+, Ubuntu 24.04+, Fedora, openSUSE, Arch and derivatives):
```sh
curl -fsSL https://raw.githubusercontent.com/Suvukaraz/leanterm/main/install.sh | sh
```
The script installs the matching package with all dependencies, verifies the download, and updates LeanTerm when run again. Remove it with `… | sh -s -- --uninstall`.

**Windows 10 (1809+) / 11:** run `leanterm_1.2.1_windows_amd64_setup.exe`. The installer is not code-signed, so SmartScreen asks once (*More info → Run anyway*).

### New: LeanEdit, the text editor on its own
- LeanTerm's editor is now also a separate application, **LeanEdit**, with its own icon and menu entry and *Open with* for text files. It runs independently of LeanTerm (`leanterm --leanedit [file…]`) and edits local files without connections, sessions or passwords.
- **Single instance by default:** files opened from the desktop, *Open with* or the command line open as new tabs of the running LeanEdit. Turn it off in LeanEdit's settings to get a new window for every file; *File → New Window* (`--new-window`) always opens one. LeanTerm's own editor window stays separate.
- **Changes on disk:** when the window gets the focus, LeanEdit offers to reload files that another program changed or deleted (like Kate); saving never overwrites such a change without asking.
- *Settings* in the menu bar opens LeanEdit's own settings window, in LeanTerm as well.
- Windows installer: LeanEdit is an optional component (Start menu and desktop shortcut, *Open with* for text files).

### Changes in LeanTerm
- *Preferences* is now called **Settings** (`--settings`; `--preferences` still works).
- Terminal screenshots and session logs: folders can be set in *Settings → Terminal Options*. After saving, the terminal shows the file with *Open folder*. *Save session log…* asks for the file name (it used to write to `/tmp`, which does not exist on Windows).

### Fixed
- Terminal: after resizing the window the shell could keep an older terminal width, so progress bars and redraws wrapped into new lines.
- Newly opened terminals (connections, local shell) become the visible tab again instead of the Info tab.
- *Open Screenshots Folder* in the Info tab did nothing.
