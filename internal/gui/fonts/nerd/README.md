`SymbolsNerdFont-Regular.ttf` is the "Symbols Only" font of
[Nerd Fonts](https://github.com/ryanoasis/nerd-fonts) v3.5.1
(`NerdFontsSymbolsOnly.zip`), MIT license (see `LICENSE`; the bundled icon sets
keep their own licenses, listed in the Nerd Fonts repository). LeanTerm uses it
for the icons of its GUI and as fallback for Nerd Font glyphs in terminals.
